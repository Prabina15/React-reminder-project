#  React Reminder

A simple and responsive reminder app built with **React.js** for creating and managing daily reminders.

###  Features

* Add, edit, and delete reminders
* Mark reminders as completed
* Set reminder date and time
* Responsive and user-friendly UI

###  Tech Stack

**React.js • JavaScript • HTML • CSS • Local Storage**

### 🚀 Run Locally

```bash
npm install
npm start
```
